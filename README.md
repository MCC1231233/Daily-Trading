## 어떻게 뽑는가

**점수는 RSI(14) 하나로만 매깁니다.** 팩터를 더하지 않는 것이 이 전략의 정의입니다.
아래는 전부 점수가 아니라 **탈락 조건**입니다.

### 1단계 — 유동성·규모 게이트 (모든 변형 공통)

| 조건 | 이유 |
|---|---|
| 관리종목·투자경고 제외 | 거래 제약과 변동성 구조가 다름 |
| 우선주·스팩·리츠·ETF 제외 | 일중 유동성과 공시 구조가 보통주와 다름 |
| 주가 2,000원 이상 / 시총 3,000억 이상 | 호가 스프레드, 수급 취약성 |
| 거래대금 50억 이상 | 진입·청산 슬리피지 방어선 |
| 전일 등락률 ±15% 이내 | 급등·급락 직후의 비대칭 갭 리스크 |
| ATR 안전 상하한 1~25% | 국면과 무관한 안전 레일 |

### 2단계 — 과매도 전략 고유 게이트 (둘뿐)

**RSI 하한 10** — 극단 과매도는 되돌림이 아니라 추세적 붕괴인 경우가 많습니다.
12년 패널에서 모멘텀 십분위가 역U자였습니다(D1 −7.3 / D5 +6.9 / D10 −5.5).
양 극단이 중간보다 나쁩니다.

**ATR 상위 20% 배제** — 12년·2,800종목·생존편향 제거 패널에서 적대적 검증
3개 렌즈(표본외·다중비교·실행비용)를 **모두 통과한 유일한 양성 규칙**입니다.
유니버스 동일가중 대비 연 +3.60%p(Newey-West t=4.76), 20~30종목 계좌에서도
증분 +3.79%p(t=4.81, 승률 90%).

주의할 점 두 가지입니다. 이것은 **수익을 늘리는 규칙이 아니라 재앙을 피하는
규칙**입니다. 그리고 **"저변동을 사라"는 근거가 없습니다** — 분위가 단조가
아니라 정보가 최상위 한 방향에만 있습니다. 그래서 점수에 넣지 않고 배제
게이트로만 씁니다.

절대 임계가 아니라 그날 후보 풀 안의 상대 위치로 겁니다. 시장 전체 변동성이
국면에 따라 몇 배씩 달라지기 때문입니다.

### 3단계 — RSI 순위

통과 종목을 RSI(14) 오름차순으로 정렬해 상위 10종목. 국면별 가중치도, 블록
분해도 없습니다.

### 4단계 — 업종 분산

점수 순으로 뽑되 한 업종에 최대 3종목까지만 배정합니다.

### 왜 단순한 쪽으로 갔는가

12년 패널 연구에서 5블록 모델이 단일 RSI를 이기지 못했고(누적 −26.5% vs
−24.8%), 라이브 14거래일에서도 같은 순서가 나왔습니다(+13.99% vs +28.14%).
복잡성이 성과를 만들고 있다는 증거가 없었습니다.

부수 효과로 **선별력이 크게 좋아집니다.** 역추세 게이트는 통과 종목이
10~20개까지 줄어 "20개 중 10개"를 뽑는 날이 많았는데(pool_health `poor`),
과매도는 200종목 이상이 통과해 20:1 수준의 선별이 가능합니다.

## 그림자 모드 — 어느 규칙이 맞는지 검증하기

매일 **4개 변형**이 같은 데이터로 각자 후보를 뽑고, 다음 실행에서 전부
채점됩니다. 발행(대시보드 메인)은 `reversal` 하나만 하고 나머지는 대조군입니다.

| 변형 | 내용 |
|---|---|
| `oversold` | **발행본.** RSI(14) 단일 팩터 |
| `reversal` | 낙폭 과다 + 저평가 + 우량성 5블록. 2026-08-20까지 발행본이었다 |
| `momentum` | 추세추종. 부호가 정반대인 대조군 |
| `reversal_timed` | 종목은 `reversal`과 동일. 코스피 전일 일중이 플러스면 매매 안 함 |

왜 필요한지는 `scripts/research/`의 분석 결과 때문입니다. 39거래일 백테스트에서
역추세는 추세추종을 크게 이겼지만(누적 -26.5% vs -53.1%), 시장 중립 구조로
바꿨을 때의 t값이 0.7 수준이었습니다. **샤프 1.8짜리 전략을 t=2로 확인하려면
약 290거래일이 필요합니다.** 백테스트를 더 돌려봐야 같은 39일을 다시 보는
것이므로, 실제 out-of-sample 데이터를 쌓는 수밖에 없습니다.

그래서 대시보드의 그림자 패널은 누적 수익률과 함께 **t값과 "판단까지 남은
거래일"** 을 항상 표시하고, **채점 20거래일이 쌓이기 전에는 유의 판정을 하지
않습니다.** 표본이 모자란 상태에서 순위를 믿는 것을 막기 위한 장치입니다.

초과수익은 `후보 평균 − 코스피 일중(시가→종가)`으로 계산합니다. 절대 수익률만
보면 전략이 좋았는지 시장이 좋았는지 구분되지 않기 때문입니다.

## 연구 스크립트

`scripts/research/`에 전략 평가에 쓴 분석이 들어 있습니다. 규칙을 바꿀 때마다
재실행해 검증할 수 있습니다.

```bash
python scripts/research/factor_test.py          # 팩터 5분위별 일중 수익률
python scripts/research/strategy_backtest.py    # 전략별 일별 시뮬레이션
python scripts/research/return_decomposition.py # 오버나이트 vs 일중 분해
python scripts/research/market_neutral_test.py  # 롱숏·지수헤지 구조 비교
python scripts/research/killswitch_test.py      # 매매를 쉴 날을 고를 수 있는가
```

2026-07-29 기준 주요 결과 (39거래일, 폭락 국면 하나이므로 일반화 주의):

- 팩터 다섯 개(20일·5일·전일 수익률, RSI, 이격도) **전부** 낮은 분위가 높은
  분위를 이겼습니다. t값 +2.8 ~ +12.1. 역추세 방향이 맞습니다.
- **혼합은 개선이 아니라 악화였습니다.** 점수 평균(-57.5%)이 최악이고,
  각 5종목씩(-43.3%)은 정확히 두 전략의 중간입니다. 상반된 신호를 평균 내면
  정보가 상쇄되고, 반반 섞으면 분산 효과가 아니라 그냥 평균을 받습니다.
- 하루 수익률을 쪼개보면 **손실 전부가 장중에 발생**했습니다.
  오버나이트 -0.003%, 일중 -0.820%. 그리고 팩터의 예측력도 장중에만 있습니다
  (오버나이트 5분위 스프레드 +0.02~0.04%p = 노이즈).
- 시장 대비 초과수익은 양수였습니다(과매도 +0.21%/일, 샤프 1.84).
  **다만 t=0.73으로 0과 구분되지 않습니다.** 알파는 시장 방향이 아니라
  종목 간 선택에 있고, 그 크기는 아직 미확인입니다.

## 성과 채점

매일 실행할 때 **직전 리포트의 후보들이 실제로 어떻게 됐는지 자동으로
채점**합니다. 각 종목의 그날 시가와 종가를 받아 `(종가/시가 - 1)`을 실현
수익률로 기록하고, 누적 통계를 사이드바와 성과 카드에 반영합니다.

사후에 규칙을 바꿔도 과거 채점 결과는 그대로 남으므로, 규칙 변경이 실제로
개선인지 확인할 수 있습니다. 휴장 등으로 시세가 없는 매매일은 `skipped`로
표시되어 통계에서 제외됩니다.

## 데이터 출처

KRX 정보데이터시스템 API는 2026년부터 로그인이 필요해져 사용하지 않습니다.

- **FinanceDataReader** — 전 종목 스냅샷(종가·거래대금·시총), 해외 지수·환율·VIX
- **네이버 금융 모바일 API** — 일별 시세, 투자자별 수급, 밸류에이션, 애널리스트 컨센서스
- **holidayskr** — 한국 법정공휴일(음력 명절·대체공휴일 포함) 판정

수집이 실패한 팩터는 중립값(z-score 0)으로 처리되고, 실패 건수는 리포트
상단에 표시됩니다. 한 종목의 수급 데이터가 빠졌다고 전체가 멈추지 않습니다.

## 구조

```
config.yaml                 규칙 파라미터 — 코드 수정 없이 여기만 바꾸면 됨
scripts/datasource.py       데이터 수집 (재시도·병렬·실패 격리)
scripts/factors.py          지표 계산 (RSI/MACD/ATR/일중 성향/수급)
scripts/variants.py         전략 변형 정의 (그림자 모드)
scripts/screen.py           오케스트레이션 + 변형별 채점 + JSON 출력
scripts/research/           전략 평가용 분석 스크립트 (파이프라인과 독립)
scripts/build_standalone.py 데이터를 인라인한 단일 HTML 빌드 (Pages 대안)
docs/index.html             대시보드 (정적, data/*.json을 fetch)
docs/data/index.json        날짜 목록 + 누적 성과 (사이드바가 읽음)
docs/data/YYYY-MM-DD.json   그날의 리포트 전문
.github/workflows/daily.yml 07:40 KST 자동 실행 → 커밋 → Pages 배포
```

## 직접 돌려보기

```bash
pip install -r requirements.txt
python scripts/screen.py
```

`docs/index.html`은 `fetch`로 데이터를 읽으므로 파일을 직접 열면 동작하지
않습니다. 로컬에서 볼 때는 서버로 띄우세요.

```bash
python -m http.server 8000 --directory docs
```

## 규칙 바꾸기

`config.yaml`만 수정하면 다음 실행부터 반영됩니다. 필터 임계값, 블록 가중치,
국면별 배분, 업종당 상한이 모두 거기 있습니다. 바꾼 뒤에는 Actions 탭에서
`Daily Screening`을 수동 실행(`workflow_dispatch`)해 결과를 바로 확인할 수
있습니다.

## 한계

- **전환 근거가 아직 유의하지 않습니다.** 과매도가 앞선 것은 14거래일
  기준이고 초과수익 t=0.88입니다. 20거래일 전에는 순위를 믿지 마세요.
- **낙폭에는 이유가 있을 수 있습니다.** 우량성 게이트는 재무·컨센서스 기준의
  방어선일 뿐, 소송·규제·수주 취소 같은 개별 악재는 걸러내지 못합니다.
  후보를 실제로 매매하기 전에 해당 종목의 최근 공시와 뉴스를 확인하세요.
- 스크리닝은 **전일 종가까지의 정보만** 사용합니다. 당일 갭, 장중 뉴스,
  실적 발표, 공시는 반영되지 않습니다.
- 실현 수익률은 시가 체결·종가 체결을 가정한 이론값입니다. 실제로는
  슬리피지와 호가 공백이 발생합니다.
- 팩터 가중치는 과거 데이터로 최적화한 값이 아니라 **사전에 정한 값**입니다.
  과최적화는 피했지만, 그만큼 이 가중치가 최선이라는 근거도 없습니다.
- 임시공휴일·특별 휴장은 `holidayskr` 갱신에 의존합니다.
